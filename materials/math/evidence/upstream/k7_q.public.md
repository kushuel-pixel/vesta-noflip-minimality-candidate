## 3. 原配置の被覆と零指数

各原語形の固定原子数をm、power数をellとする。token前の境界B_i、power内部R_i、最終境界B_hを時系列で並べる。slot数はm+2ell+1。二つのslotを弱昇順で選び、共役event0,event1にそれぞれ原ID6..13を与える。同slotでもevent0→event1を保持する。全347語形でslot弱昇順対51,684、64倍3,307,776を確認した。ell<=5、m<=13、slot<=24。

同じpower内部にr個の共役が入れば、そのpowerをr+1個のfragment u>=0へ分割し、元指数 e_j は該当fragmentの和とする。`original_exponents` がこの和の添字を保持する。境界表現と内部offset0などの重複は消さない。`raw_tokens` はpowerの原IDと固定原子、二つのeventをそのまま記す。

任意の対象列から共役を消して得る骨格はP1/P2で原347語形のいずれかへ戻る。元gapを、その語形のtoken境界又はrun内部のoffsetへ移せば、非負fragmentの和を元指数へ保ったまま同じraw列をliteralに復号できる。offsetが境界の場合も0を許すので被覆から落ちない。同gapの元共役順序をevent順で保持する。逆にこの復号は原IDを変更せず、原予算・raw guardを満たすとき指定原域の列を与える。有限件数の照合だけをこの被覆論証の代用にはしていない。

予算は必ず n=m+Σu-5。支持Sごとに、i∉Sならu_i=0、i∈Sならu_i=1+x_j、x_j>=0とする。d=|S|に対して Σx>=B=30-m-d。全零支持はn=m-5<=8なので原域空。全保持セルでB>0を確認した。nを独立変数にしない。

## 4. 全raw guardの必要十分条件

共役event又は固定Nielsen原子が間に無い二つのNielsen tokenについて、両端の原IDが逆対なら、少なくとも一方のpower端点が0で消えるか、間のpowerの少なくとも一つが正でなければならない。これは各potential inverse adjacencyに対応するCNFである。共役eventは消えない障壁なので、共役を消した骨格へ先にguardを課していない。

支持が固定されるとrawでの隣接関係も固定される。各positive runの長さを1として独立に復号し、全支持について実際の隣接判定とCNFを照合する。長い同ID反復は逆対を作らず、0/正だけでguardが決まる。この検査は全零支持も判定した上で、予算による除外と区別する。

空配置は41,845、非空配置9,839。非空支持セル69,509、64共役対込み4,448,576枝。表示数が元配置数より増えるのは、同じ原配置の指数域を排他的な零/正支持に分割したためである。境界で別slotの表示が重なることは許す。

## 5. 実prefixとQ条件

M0=[[0,-1],[1,-n]]から原時系列に左作用させる。ID2^uは[[1,u],[0,1]]、ID5^uは[[1,0],[-u,1]]、ID3/4はそれぞれ単位原子の逆向き行操作である。各event直前の実状態M1,M2と、その時点のNielsen数gapを保存する。操作積だけをprefixと呼ばない。全セルで終端I、det M1=det M2=1を係数恒等式で確認する。同gapのM1=M2は同じ更新状態から記録される。

原Q積は (a,b,c)(A,B,C)=(a+A,b+B,c+C-bA)。初期Q状態は ((0,-1,-n),(1,-n,0))。P4の純Nielsen終端Q中心は (n²+1,n)。共役iの選択行を(A_i,B_i)、対象成分j_iとし、x^epsilon共役ならdelta_i=epsilon B_i、y^epsilon共役ならdelta_i=-epsilon A_i。D_iはその成分だけにdelta_iを持つ列である。共役による可換化変化はないので、Q中心の最終差は純Nielsen suffixで線形輸送される。

従って必要十分な二式は

    Z=(n²+1,n)^T + M1^-1 D1 + M2^-1 D2 = 0.

実際のM_i、nの予算式を代入した後、(Z1-nZ2,Z2)へ移す。これは整数域で可逆。多項式の定数行操作・非零整数によるprimitive化のみで51,034クラスへ集約し、全元セル/IDへの写像を保存した。変数による除算は一度もない。

原lambda=1の64系のz1,z2は、九変数の段階で独立の有理多項式演算により128係数恒等式を確認し、分母倍率はいずれも1だった。したがって全実prefixへの代入にも一致する。Q二式のlambda非依存性をk=1の配置・高次基準項の流用と混同しない。

H式は今回新たに計算・制約として使用していない。保存する原定義・原128系にはlambda=1のH基準、chi補正、第二共役actual-zの交差項がそのままある。後段はそれらを保持して別途評価する必要がある。本Q結果からH通過も自由群成功も推定しない。

## 6. 全域除外と解の全記述

最初の50,919クラスには整数非負係数下界を付けた。二式の整数線形結合pを符号調整し、非定数係数を全て非負にする。各変数の純冪係数和をa_i、定数をcとすると、整数x_i>=0では x_i^r>=x_i (r>=1) より

    p(x) >= c + Σ a_i x_i >= c+B min_i(a_i) > 0.

従って元二式の同時零はない。係数・線形結合・下界は各証明書に保存する。別の1クラスはT=ceil(B/d)として、少なくとも一つのx_i>=Tという全被覆を使う。各座標枝をx_i=T+y_iへ移し、残予算B-Tに同じ厳密正下界を付けた。有限点検査ではない。

残った114クラスは、係数±1のaffine pivotを順に消去し、元xのlift・全非負条件・予算不等式を保存した。これにより54クラスは残式が正定数を持つ非負係数多項式、2クラスは一次係数のgcdが定数を割らない整数障害、8クラスは残る域不等式が常に負となり除外できた。

残る50クラスはQ解を全記述した。30クラスはaffine消去後にQ等式がなく、20クラスは残式のある変数の係数が非零定数で、その変数は他の単項式に現れないため直接解ける。解の定数分母は高々2である。自由パラメータt_iは元の残存x座標なので非負整数とする。分母2の分子が偶数であること、復元する全x>=0、Σx>=Bを明記した。未解決多項式等式はない。

`Q_RESIDUAL_TABLE.md` に50行の全パラメータ式・不等式・合同条件を表示し、JSONを機械的な正本データとする。定数pivot消去は逆向きにも一意に復元できるため必要十分。条件を満たす任意のtから全整数xを得て元Q二式が恒等的に0になること、元解から残存座標tを取れば同じ式へ戻ることが従う。各50行は少なくとも一つの合法な証人を持つ。

最終クラス数はQ解なし50,984、全解記述50、未解決0。支持付き枝ではQ解なし4,447,988、全解記述588。これは元配置ごとの分類に再集約され、上記2,678,080 / 629,454 / 242 / 0となる。

## 7. 元列への復元手順

1. SOLUTION_LIFTSの一行を選び、そのsolution_idの全条件を満たす整数パラメータtを取る。
2. rational polynomial mapsから元支持座標xを得る。合同条件により分母は正確に割り切れる。
3. 指定positive_fragment_indicesへu=1+xを置き、他を0とする。original_exponent_fragment_groupsに従って元指数を和として復元する。
4. n=m+Σu-5、q=n+5、L=n+7を復元する。budget不等式によりn>=25。
5. 指定template checkpointのraw_tokensを元IDで展開し、event0,event1に記載の共役IDをその順序で入れる。保存されたoriginal_gapsを同じxで評価する。

逆写像は原骨格被覆→slot/offset→支持→クラス→消去の残存座標の順で存在する。0のrun、境界offset、同slot、同gapを途中で削除・並べ替えない。別表示間の重複を除いた原列数は主張していない。
